# 输入图像来源

- `7.PNG`、`10.jpg`、`11.jpg`、`16.jpg`：来自任务压缩包《实验二 图像增强的频域方法》，保留原始尺寸；这四幅图只有受周期噪声版本，没有对应的干净参考图。
- `cameraman.tif`：本机 MATLAB R2023b 安装目录 `toolbox/images/imdata/cameraman.tif` 中的 256×256 灰度样例。以此图作为自然场景输入，生成已知随机种子的高斯噪声配对图，用于低通滤波的 PSNR 比较和高通边缘增强。

合成陷波半径搜索以每张课程给定图像作为“加入可控调幅正弦噪声前”的参考。该 PSNR 只评价对新增合成噪声的恢复，不代表原始四张周期噪声图的真实恢复质量。
